# IronStride

A private, offline-first hybrid athlete PWA: gym sessions, running plan, vegan nutrition, and progress tracking in one place. Built for personal use on an Android phone.

## Development

```bash
npm install
npm run dev          # dev server
npm test             # unit tests
npm run typecheck && npm run lint
npm run build        # production build to dist/
```

## Status

Under active development.
